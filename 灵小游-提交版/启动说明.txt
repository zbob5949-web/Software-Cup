## 📋 环境要求

- Python 3.10+
- 能够访问外网（调用 DeepSeek API 和通义 Embedding API）

> 无需安装 Node.js、无需 MySQL。系统使用 SQLite 本地数据库，前端已预编译。

═══════════════════════════════════════════════════════

## 🚀 三步启动

### 第一步：配置 API Key

编辑项目根目录下的 `.env` 文件，填入两个必填 Key：

```
DASHSCOPE_API_KEY=你的通义Key    ← 必填，https://dashscope.aliyun.com/
DEEPSEEK_KEY=你的DeepSeekKey     ← 必填，https://platform.deepseek.com/
```

> 两个 Key 均为免费额度即可运行。Azure Key 可留空（自动使用免费 edge-tts）。

### 第二步：安装 Python 依赖

```bash
cd 灵小游-提交版
pip install -r requirements.txt
```

### 第三步：启动

```bash
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
```

启动成功后浏览器打开 → **http://localhost:8000**

## 🎯 核心功能演示路径

### 游客端
1. 首页看到 Live2D 数字人"灵小游"，语音播报欢迎语
2. 底部输入框打字提问（或点麦克风语音提问）
3. 数字人语音回答 + 口型同步 + 表情互动
4. 推荐测试问题：
   - "灵山大佛有什么故事？"
   - "帮我规划2小时游览路线"
   - "门票多少钱？"
   - "九龙灌浴几点有演出？"
   - "今天天气怎么样？"

### 管理后台
1. 登录 → 数据大屏（服务人次/热门问题/满意度）
2. 知识库管理 → 增删改查知识条目
3. 形象管理 → 配置数字人语音/语速/形象
4. 数据统计 → 情感分析/来源分布/趋势图

## 📂 项目结构

```
灵小游-提交版/
├── app/                    后端源码（Python FastAPI）
│   ├── main.py             FastAPI 入口
│   ├── database.py         SQLite 数据库（预置景区/FAQ/管理员）
│   ├── core/               配置 & JWT 安全模块
│   ├── routers/            所有 API 路由
│   ├── services/           业务逻辑（对话/向量检索/天气）
│   ├── digital_human/      Live2D 数字人前端资源
│   └── admin/              管理后台页面
├── frontend/
│   ├── src/                前端源码（React + TypeScript）
│   └── dist/               前端构建产物（已编译，可直接访问）
├── data/
│   ├── lingshan.db         SQLite 数据库（含预置数据）
│   ├── chroma_db/          向量知识库索引（已预构建）
│   ├── models/             Embedding 模型文件
│   └── lingshan/           景区知识库原始资料
├── scripts/                辅助脚本
├── .env                    环境变量配置（需填入API Key）
├── .env.example            环境变量模板
├── requirements.txt        Python 依赖
├── 产品部署与使用手册.md   详细部署文档
└── 启动说明.txt            本文件
```
